## Live API (Render)

You can test the API here: **https://contacts-api-e9b9.onrender.com**

- Health: `GET /health`
- Contacts: `GET /api/contacts`
- Create: `POST /api/contacts`
- Get by id: `GET /api/contacts/:id`
- Update: `PUT /api/contacts/:id`
- Toggle favorite: `PATCH /api/contacts/:id/favorite`
- Delete: `DELETE /api/contacts/:id`
